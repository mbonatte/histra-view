# Historical documentation archive

These files preserve development history. Version numbers, worktree descriptions,
test counts, measurements and release-approval statements refer to their original
milestones. They are not current package instructions or release qualifications.

- `releases/v1/`: original V1.0.0 implementation plan, review and checklist.
- `refactoring/`: the 2026-08-28 architecture/refactoring progress record.
- `histra_documentation_snapshot/`: superseded module and architecture snapshots.
- `audits/`: original audit deliverables, patches and summaries.
- `benchmarks/`, `generated/`: historical measurements and generated summaries.
- `superseded/`: previous workflow descriptions and handoffs.

Use the [documentation index](../README.md), [current status](../STATUS.md), and
[release workflow](../release/README.md) for maintained guidance. Some historical
records mention external or retired generated artifacts that are not retained
in the current checkout.
